# TIME NOTE V1

スマホで「今やっていること」を1タップで切り替え、24時間の使い方を記録する個人用PWA。

## V1の目的
- 睡眠時間を正確に把握する
- AI作業時間を日単位で把握する
- SNS/Uber/その他の時間消費を可視化する
- 0:00〜24:00のタイムラインで直感的に振り返る
- CSVで記録を外部出力できるようにする

## 開発方針
- スマホ優先
- PWA（HTML/CSS/JavaScript）
- サーバー・ログインなしで開始
- 同時稼働は常に1カテゴリ
- 新カテゴリを押すと現在カテゴリを終了して即切替
- 同じカテゴリを再度押すと停止
- 記録は開始・終了の時刻を保存し、画面を閉じても継続
- V1は機能追加より操作の速さと記録の壊れにくさを優先
